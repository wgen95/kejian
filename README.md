# 课间 · 同济课表

当前版本 **0.3.3 试用版**。面向 Android 16（API 36），最低 Android 8.0。简洁周课表、无广告、课程保存在手机。

## 本版登录回跳修复

根据 Neo7 提供的真实加载记录修正两类 GET 导航：

- 学校返回 `http://1.tongji.edu.cn/ssologin`（及 `/sslogin`）时，升级到同一路径的 HTTPS，完整保留原始登录查询参数与片段。
- 学校回调路径误拼成 `/api/ssoservice/system/loginIn;https://1-443.webvpn.tongji.edu.cn/;https://onetest.tongji.edu.cn` 时，仅去掉这一条已确认的后缀，保留当次 code、state 等原始参数。

修正在请求发出前进行，只处理准确学校主机、默认端口、主页面 GET。正常网址、POST、其它域名和其它后缀不改写；不放开明文请求或证书错误。同一修正目标重复出现时停止回跳，提示从首页开启新登录。刷新或恢复登录回调页时也从首页重新登录，避免重放一次性参数。

默认仍从 `https://1.tongji.edu.cn/` 打开，由学校生成认证会话。浏览器保持 JavaScript、DOM 存储、Cookie、当前内核版本的手机标识、新窗口在当前页面打开、电脑模式和横屏。学校网页排版保持原样。

加载到 100% 不代表业务登录完成。登录返回接口未继续跳转时显示真实等待阶段；加载信息记录最近 24 条事件和相对时间，查询参数仅显示 code/state/uid/token 是否存在，不显示值。

安装包已构建并完成签名检查。参数保留逻辑与 Android 16 原生客户端的修正语义已验证；真实账号在 Neo7 上是否完整进入个人课表仍需用户实际使用确认。

## 安装和导入

1. 将 `dist/Kejian-0.3.3.apk` 传到手机安装，可覆盖更新此前同签名版本。
2. 点击「从教务系统导入」或「全部课程 → 导入课表」，打开应用内浏览器。
3. 在学校统一身份认证页面登录，找到「我的选课 → 个人课表」。地址栏可填写教务网址；默认从学校主页开始，等待学校自动跳转到统一认证页面。
4. 选择需要的学期并筛选，等课程数据加载完成，再点右下角「导课」。
5. 在预览中核对课程、教师、地点、周次、开学第一周周一和学期周数。可逐条修改、取消勾选，选择合并或替换后保存。
6. 首次使用在设置中校准作息。初始作息是示例。

浏览器提供电脑/手机模式切换、横屏/竖屏切换、「打不开？」帮助、刷新、返回教务首页、清除登录缓存后重新登录。横屏切换保留当前浏览器实例，不主动重新加载页面。学校页面布局保持原样。

## 当前功能

- 原生周课表和所有课程列表；新增、编辑、删除课程。
- 每条安排保留完整周次，支持单双周、不连续周次、同一课程不同教师/教室和重叠课程。
- 学期日期、周数、作息设置、回到本周和周末显示。
- 内置浏览器登录、网址输入、导课、导入核对和本地保存。
- 从学校课程列表优先读取原始排课，避免受到课表网格合并显示的影响。
- 读取失败、读取超时或页面跳转时，已有课表不会自动覆盖；导入前必须确认保存。
- JSON 备份导出和恢复，通过系统文件选择器访问指定文件。
- 界面统一使用「个人课表」「同济课表」，不区分学生类别。

## 权限和数据

新版清单只声明联网权限。导入在应用内完成，不使用跨应用链接、剪贴板、悬浮窗或无障碍服务。

学校账号在学校网页内输入。读取脚本只访问课表和学期字段，不读取登录输入框、Cookie 或浏览器存储。没有广告或统计 SDK。课表通过应用私有缓存带到导入预览，确认后写入本地。加载记录仅暂存在内存，不记录账号、密码、Cookie 或查询参数。

登录会话由应用内浏览器缓存；可在「打不开？」中清除。卸载或清除应用数据会删除课程，建议先导出备份。本应用是个人工具，与同济大学无隶属关系。

- 依据 2026-10-13 检查的同济公开前端组件进行适配，读取 `timeTableList` 和 `weeks/dayOfWeek/timeStart/timeEnd` 等字段。

- **尚未在 realme Neo7 上验证新版，尚未输入真实账号验证登录到个人课表的完整流程。** 模拟器验证覆盖了之前失败的初始打开和登录页跳转，不能作为真实账号导课通过的证明。
- 学校更新组件后可能需要调整。缺少有效周次/节次或无法识别名称的安排会提示核对，不会猜测生成课程。无具体排课的课程须按学院通知手动添加。
- 当数据带有学期编号时，检查其是否与所选学期一致；仍需等待页面筛选完成再导课。
- 开学第一周周一要按教学周定义核对，节假日调休暂需手动调整。

## 构建

原生 Java + Android Views/WebView，无第三方运行时依赖。Android Studio 可使用 AGP 8.10.1 / Gradle 8.11.1 / JDK 17+ / SDK 36。

也可使用官方构建工具直接构建：

```powershell
.\build.ps1 -SdkRoot '你的安卓SDK目录' -JavaHome '你的JDK目录'
```

SDK 目录需包含 `platforms/android-36` 和 `build-tools/36.0.0`。测试签名密钥在 `.private/local-test.jks`，保留密钥才能覆盖升级；源码包不含密钥、开发工具或学校前端下载文件。

读取脚本位于 `app/src/main/assets/tongji-extract.js`，测试说明见 `tests/README.md`。技术参考：[WebView 官方说明](https://developer.android.com/develop/ui/views/layout/webapps/webview)、[安卓 16 SDK 设置](https://developer.android.com/about/versions/16/setup-sdk)。
